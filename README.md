# gabrielolvv.github.io

Portfolio of Gabriel Oliveira, a backend-focused full-stack developer.

**Live site:** https://gabrielolvv.github.io/

## Structure

A static site with no build step: hand-written HTML, CSS and JavaScript, with
an English/Portuguese language switch.

```
dist/
  index.html            home page
  prism-review/         Prism Review case study
  404.html              not-found page
  og.jpg                social sharing image (1200×630)
  resume.pdf            résumé
  robots.txt, sitemap.xml
scripts/
  build_resume.py       generates dist/resume.pdf
```

## Run locally

```bash
python -m http.server 8000 --directory dist
```

Then open http://localhost:8000.

## Résumé

`dist/resume.pdf` is generated by [`scripts/build_resume.py`](scripts/build_resume.py).
To update it, edit the content in the script and run:

```bash
pip install reportlab
python scripts/build_resume.py
```

## Deployment

Every push to `main` publishes the `dist/` folder to GitHub Pages through the
[`.github/workflows/pages.yml`](.github/workflows/pages.yml) workflow.
